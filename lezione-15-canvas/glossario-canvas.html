Lezione 15 — Canvas

🎨 Il Canvas HTML

Guida completa e interattiva al disegno 2D con JavaScript. Ogni sezione ha spiegazione, codice ed esempio dal vivo: premi Esegui per vedere il risultato.

1 Cos'è il Canvas

Il tag <canvas> è un elemento HTML che funziona come una tela vuota: di per sé non mostra nulla, è solo un rettangolo bianco (o trasparente) su cui possiamo disegnare usando JavaScript. Tutto quello che vedrai su un canvas — rettangoli, cerchi, linee, testo, immagini — viene disegnato riga per riga di codice, non con HTML o CSS.

Si inserisce in una pagina HTML esattamente come qualsiasi altro tag:

<canvas id="mioCanvas" width="500" height="400"></canvas>

L'attributo id ci serve per "agganciarlo" da JavaScript. Gli attributi width e height definiscono la risoluzione reale del disegno, cioè quanti pixel abbiamo a disposizione per disegnare.

Collegare JavaScript al canvas

Per poter disegnare servono due passaggi, sempre uguali:

  1. getElementById("mioCanvas") — prendo il riferimento al tag canvas nella pagina, come faremmo con qualunque altro elemento HTML.
  2. .getContext("2d") — chiedo al canvas il suo "contesto di disegno 2D". Questo oggetto (di solito chiamato ctx) è quello che contiene tutti i metodi per disegnare: fillRect, arc, fillText e così via. Da questo punto in poi, ogni comando di disegno parte da ctx.

Il sistema di coordinate

Il canvas usa un sistema di coordinate diverso da quello che si studia in matematica. Il punto (0, 0) si trova nell'angolo in alto a sinistra, non al centro. Da lì:

  • l'asse X cresce andando verso destra (come al solito);
  • l'asse Y cresce andando verso il basso (al contrario della matematica classica!).

Quindi il punto (400, 300) su un canvas 500×400 si trova in basso a destra, vicino all'angolo. È l'errore più comune per chi inizia: pensare che Y cresca verso l'alto come sui grafici cartesiani.

Canvas vs SVG

Sono due modi diversi per disegnare grafica sul web e vale la pena capire la differenza:

CanvasSVG
Come funzionaè una griglia di pixel (bitmap): si "dipinge" e il canvas non ricorda le forme disegnateè un insieme di forme vettoriali descritte in XML: ogni forma resta un elemento nel DOM
Modificheper cambiare qualcosa bisogna ridisegnare (spesso tutto)si può modificare un singolo elemento come si farebbe con l'HTML
Prestazioniottimo con tante forme o animazioni veloci (giochi, grafici dati in tempo reale)ottimo con poche forme che devono restare nitide a ogni zoom
Ridimensionamentoperde qualità se ingrandito (è una bitmap)resta sempre nitido (è vettoriale)

width e height: attributi HTML, non CSS!

Questo è un punto delicato. Il canvas ha due dimensioni diverse che è facile confondere:

  • width/height come attributi HTML (<canvas width="500" height="400">) — definiscono la vera risoluzione del sistema di coordinate su cui disegniamo.
  • width/height impostati via CSS (es. canvas { width: 500px; }) — cambiano solo la dimensione visiva sullo schermo, deformando il disegno se non rispettano le proporzioni originali, un po' come stirare una fotografia.

Regola pratica: imposta sempre width e height come attributi HTML (o via JavaScript con canvas.width = 500), ed evita di ridimensionare il canvas con il CSS a meno che tu non sappia esattamente cosa stai facendo.

💻 Codice di esempio

const canvas = document.getElementById("canvas-1");
const ctx = canvas.getContext("2d");

// bordo esterno del canvas
ctx.strokeStyle = "#888";
ctx.lineWidth = 2;
ctx.strokeRect(0, 0, canvas.width, canvas.height);

// asse X (rosso) e asse Y (blu), partendo dall'origine (0,0)
ctx.strokeStyle = "red";
ctx.beginPath();
ctx.moveTo(0, 20);
ctx.lineTo(canvas.width, 20);
ctx.stroke();

ctx.strokeStyle = "blue";
ctx.beginPath();
ctx.moveTo(20, 0);
ctx.lineTo(20, canvas.height);
ctx.stroke();

ctx.fillStyle = "black";
ctx.font = "14px Arial";
ctx.fillText("(0,0)", 25, 15);

2 Rettangoli

I rettangoli sono la forma più semplice del canvas: a differenza di cerchi o linee, non serve costruirli con un "percorso" (vedremo i path nella sezione 3), esistono metodi diretti già pronti.

MetodoCosa fa
fillRect(x, y, w, h)disegna un rettangolo pieno, colorato con fillStyle
strokeRect(x, y, w, h)disegna solo il bordo del rettangolo, colorato con strokeStyle
clearRect(x, y, w, h)cancella (rende trasparente) tutto ciò che si trova in quell'area rettangolare, canvas compreso

In tutti e tre i casi i parametri sono gli stessi: x e y sono le coordinate dell'angolo in alto a sinistra del rettangolo, w e h sono larghezza e altezza.

fillStyle — il colore di riempimento

Prima di chiamare fillRect, si imposta il colore con ctx.fillStyle. Accetta diversi formati, tutti validi:

  • nome colore: ctx.fillStyle = "orange"
  • esadecimale: ctx.fillStyle = "#ff8800"
  • rgb(): ctx.fillStyle = "rgb(255, 136, 0)"
  • rgba(): ctx.fillStyle = "rgba(255, 136, 0, 0.5)" — il quarto valore è la trasparenza, da 0 (invisibile) a 1 (opaco)

strokeStyle e lineWidth

ctx.strokeStyle funziona esattamente come fillStyle ma imposta il colore del bordo, usato da strokeRect (e più avanti da stroke()). ctx.lineWidth imposta lo spessore del bordo in pixel (default: 1).

Attenzione: fillStyle, strokeStyle e lineWidth restano "attivi" per tutti i disegni successivi finché non li cambi di nuovo — non vanno reimpostati ad ogni forma se il colore non cambia.

💻 Codice di esempio

const ctx = canvas.getContext("2d");

// rettangolo pieno
ctx.fillStyle = "#4f8ef7";
ctx.fillRect(30, 30, 120, 80);

// rettangolo solo bordo, spessore 4px
ctx.strokeStyle = "#e63946";
ctx.lineWidth = 4;
ctx.strokeRect(190, 30, 120, 80);

// rettangolo semi-trasparente con rgba
ctx.fillStyle = "rgba(46, 204, 113, 0.6)";
ctx.fillRect(90, 130, 120, 80);

// cancella un pezzo di quello pieno sopra
ctx.clearRect(60, 50, 40, 30);

3 Path (Percorsi)

Per disegnare qualsiasi forma diversa da un rettangolo (triangoli, stelle, forme irregolari, linee spezzate...) si usa un path, cioè un percorso costruito punto dopo punto, come se si muovesse una penna sul foglio.

MetodoCosa fa
beginPath()inizia un nuovo percorso, azzerando quelli precedenti
moveTo(x, y)sposta la "penna" nel punto (x, y) senza disegnare nulla
lineTo(x, y)traccia una linea dal punto attuale fino a (x, y), e quel punto diventa il nuovo punto attuale
closePath()chiude il percorso tracciando una linea dall'ultimo punto fino al punto di partenza
stroke()rende visibile il percorso disegnando solo il bordo
fill()riempie l'area del percorso con fillStyle

La sequenza tipica è sempre la stessa: beginPath() → uno o più moveTo/lineTo → eventualmente closePath() → stroke() e/o fill().

Differenza fra stroke() e fill()

stroke() disegna solo il contorno del percorso (usa strokeStyle e lineWidth), lasciando l'interno vuoto/trasparente. fill() invece riempie tutta l'area chiusa dal percorso (usa fillStyle) — e funziona anche se non hai chiamato closePath(), perché fill() chiude automaticamente la forma "virtualmente" prima di colorarla. Puoi anche chiamarli entrambi sullo stesso percorso, per avere sia riempimento che bordo ben visibile.

Un dettaglio importante su beginPath()

Se dimentichi beginPath() prima di un nuovo disegno, il canvas continuerà ad aggiungere punti al percorso precedente invece di iniziarne uno pulito, causando forme strane collegate fra loro con linee indesiderate. Regola pratica: ogni forma nuova comincia con beginPath().

💻 Codice di esempio (triangolo)

ctx.beginPath();
ctx.moveTo(100, 20);   // punta in alto
ctx.lineTo(160, 120);  // in basso a destra
ctx.lineTo(40, 120);   // in basso a sinistra
ctx.closePath();       // torna alla punta
ctx.fillStyle = "#f4a300";
ctx.fill();
ctx.strokeStyle = "black";
ctx.stroke();

L'esempio dal vivo qui sotto disegna un triangolo, una stella a 5 punte e una forma irregolare, tutte costruite solo con moveTo/lineTo.

4 Cerchi e Archi

Il canvas non ha un metodo circle(): cerchi, semicerchi e spicchi si disegnano tutti con un unico metodo, arc(), che in realtà disegna un arco di circonferenza — un cerchio completo è semplicemente un arco da 0 a 360 gradi.

ctx.arc(x, y, raggio, angoloInizio, angoloFine, sensoAntiorario)
  • x, y — il centro della circonferenza (non l'angolo come nei rettangoli!)
  • raggio — il raggio in pixel
  • angoloInizio, angoloFine — da dove a dove disegnare l'arco, in radianti
  • sensoAntiorario — parametro opzionale booleano: true disegna in senso antiorario, false (default) in senso orario

Gli angoli sono in radianti, non in gradi

Questo è il punto che confonde di più all'inizio. Il canvas non usa i gradi (0-360) ma i radianti. I riferimenti principali da ricordare:

  • 0 → punta verso destra (le 3 in punto su un orologio)
  • Math.PI / 2 → punta verso il basso
  • Math.PI → punta verso sinistra (mezzo giro, 180°)
  • 2 * Math.PI → giro completo (360°), torna al punto di partenza

Se preferisci ragionare in gradi (più intuitivo), puoi sempre convertirli al volo con la formula:

radianti = gradi * Math.PI / 180

Esempio: un quarto di cerchio (90°) si scrive 90 * Math.PI / 180, che equivale a Math.PI / 2.

Le quattro varianti principali

FormaCome si ottiene
Cerchio pienoarc(x, y, r, 0, 2*Math.PI) + fill()
Cerchio vuoto (solo bordo)arc(x, y, r, 0, 2*Math.PI) + stroke()
Semicerchioarc(x, y, r, 0, Math.PI) + fill()/stroke()
Spicchio (fetta di torta)moveTo al centro + arc(...) + closePath() + fill()

Per lo spicchio serve un trucco: prima di disegnare l'arco bisogna spostarsi con moveTo(x, y) nel centro del cerchio, così che closePath() tracci i due "raggi" che chiudono la fetta, invece di lasciare solo l'arco esterno.

💻 Codice di esempio

// cerchio pieno
ctx.beginPath();
ctx.arc(80, 90, 60, 0, 2 * Math.PI);
ctx.fillStyle = "#4f8ef7";
ctx.fill();

// cerchio vuoto
ctx.beginPath();
ctx.arc(230, 90, 60, 0, 2 * Math.PI);
ctx.strokeStyle = "#e63946";
ctx.lineWidth = 3;
ctx.stroke();

// semicerchio
ctx.beginPath();
ctx.arc(380, 90, 60, 0, Math.PI);
ctx.fillStyle = "#2ecc71";
ctx.fill();

// spicchio (fetta) di 90 gradi
ctx.beginPath();
ctx.moveTo(80, 220);
ctx.arc(80, 220, 60, 0, 90 * Math.PI / 180);
ctx.closePath();
ctx.fillStyle = "#f4a300";
ctx.fill();

5 Testo

Il canvas può scrivere testo con due metodi speculari a quelli dei rettangoli e dei path:

MetodoCosa fa
fillText(testo, x, y)scrive testo pieno, colorato con fillStyle
strokeText(testo, x, y)scrive testo solo bordo (contorno delle lettere), colorato con strokeStyle

Le coordinate x, y indicano dove posizionare il testo, ma il punto esatto dipende da textAlign e textBaseline (vedi sotto).

font

Prima di scrivere si imposta il font con la stessa sintassi del CSS, come stringa unica:

ctx.font = "20px Arial";
ctx.font = "bold 32px Georgia";

textAlign — allineamento orizzontale

Decide come il testo si posiziona rispetto alla coordinata x:

  • "left" (default) — il testo inizia da x, si estende verso destra
  • "center" — x è il centro orizzontale del testo
  • "right" — il testo termina in x, si estende verso sinistra

textBaseline — allineamento verticale

Decide come il testo si posiziona rispetto alla coordinata y:

  • "top" — y è il bordo superiore del testo
  • "middle" — y è il centro verticale del testo
  • "bottom" — y è il bordo inferiore del testo

Per centrare perfettamente un testo dentro un rettangolo o un canvas, la combinazione giusta è textAlign = "center" + textBaseline = "middle", usando come x,y il centro esatto dell'area.

measureText()

A volte serve sapere quanto è largo un testo prima di disegnarlo (per centrarlo manualmente, o per capire se sta dentro uno spazio). Si usa:

const larghezza = ctx.measureText("Ciao mondo").width;

Restituisce un oggetto con diverse informazioni sulla misura del testo; la proprietà .width è quella usata più spesso.

💻 Codice di esempio

// testo centrato nel canvas
ctx.font = "bold 28px Arial";
ctx.fillStyle = "#333";
ctx.textAlign = "center";
ctx.textBaseline = "middle";
ctx.fillText("Testo centrato", canvas.width / 2, 60);

// testo solo bordo (contorno)
ctx.font = "bold 40px Arial";
ctx.strokeStyle = "#4f8ef7";
ctx.lineWidth = 1.5;
ctx.strokeText("CONTORNO", canvas.width / 2, 140);

// misura del testo
ctx.font = "16px Arial";
const testo = "Questo testo è largo:";
const larghezza = ctx.measureText(testo).width;
ctx.textAlign = "left";
ctx.fillStyle = "#555";
ctx.fillText(testo + " " + Math.round(larghezza) + "px", 20, 200);

6 Testo Verticale

Il canvas non ha un modo diretto per scrivere testo ruotato: non esiste una proprietà tipo textDirection = "vertical". Il trucco è ruotare l'intero sistema di coordinate, scrivere il testo normalmente (orizzontale), e poi riportare gli assi come erano prima. Per farlo servono quattro metodi:

MetodoCosa fa
save()salva una "fotografia" dello stato attuale del contesto (trasformazioni, colori, font...)
translate(x, y)sposta l'origine (0,0) degli assi nel punto (x, y)
rotate(angolo)ruota gli assi (in radianti) attorno alla nuova origine
restore()ripristina lo stato salvato con l'ultimo save(), annullando translate/rotate

Lo schema passo per passo

Per scrivere del testo verticale (ad esempio ruotato di -90°, dal basso verso l'alto) la sequenza è sempre questa:

  1. ctx.save() — metto da parte lo stato "normale" del contesto
  2. ctx.translate(x, y) — sposto l'origine nel punto dove voglio scrivere il testo
  3. ctx.rotate(-Math.PI / 2) — ruoto gli assi di 90° in senso antiorario
  4. ctx.fillText("...", 0, 0) — scrivo il testo a partire dalla nuova origine (0,0), che ora corrisponde al punto (x, y) di prima ma ruotato
  5. ctx.restore() — riporto gli assi come erano, pronti per disegnare altro normalmente

Perché serve save()/restore()

Se ti dimentichi restore() dopo aver ruotato, la rotazione resta attiva per sempre: tutto quello che disegni dopo (rettangoli, altro testo, cerchi...) risulterà ruotato e spostato, anche se nel tuo codice sembra "normale". È un errore molto comune e difficile da individuare, perché il codice successivo è scritto correttamente ma il sistema di riferimento sotto di esso è cambiato. La coppia save()/restore() funziona come delle parentesi: tutto quello che sta in mezzo è "temporaneo", tutto quello che sta fuori resta normale.

💻 Codice di esempio

ctx.save();                      // 1. salvo lo stato
ctx.translate(30, 220);          // 2. sposto l'origine nel punto (30, 220)
ctx.rotate(-Math.PI / 2);        // 3. ruoto di -90°
ctx.font = "bold 18px Arial";
ctx.fillStyle = "#333";
ctx.textAlign = "center";
ctx.fillText("Quantità", 0, 0);  // 4. scrivo alla nuova origine (0,0)
ctx.restore();                   // 5. ripristino gli assi normali

// da qui in poi disegno normalmente, senza rotazione
ctx.fillStyle = "#4f8ef7";
ctx.fillRect(100, 100, 60, 100);

7 Colori e Stili

Abbiamo già visto fillStyle e strokeStyle nella sezione 2. Qui approfondiamo tutti i modi in cui puoi definire un colore, più due strumenti avanzati: la trasparenza globale e i gradienti.

I quattro formati di colore

FormatoEsempio
Nome colorectx.fillStyle = "tomato"
Esadecimalectx.fillStyle = "#ff6347"
rgb()ctx.fillStyle = "rgb(255, 99, 71)"
rgba()ctx.fillStyle = "rgba(255, 99, 71, 0.5)" (il 4° valore è la trasparenza, 0-1)

globalAlpha — trasparenza globale

Mentre rgba() rende trasparente un singolo colore, ctx.globalAlpha rende trasparente tutto quello che disegni dopo, indipendentemente dal colore usato. Va da 0 (completamente invisibile) a 1 (completamente opaco, il default). È utile per dissolvenze o per sovrapporre forme senza nascondere quello che c'è sotto. Come per fillStyle, resta attivo finché non lo cambi di nuovo — ricordati di riportarlo a 1 se non vuoi che tutto il resto del disegno sia trasparente!

Gradienti lineari

Un gradiente lineare sfuma il colore lungo una linea retta (es. da sinistra a destra). Si costruisce in due passaggi:

const gradiente = ctx.createLinearGradient(x0, y0, x1, y1);
gradiente.addColorStop(0, "colore iniziale");
gradiente.addColorStop(1, "colore finale");
ctx.fillStyle = gradiente;

createLinearGradient(x0,y0, x1,y1) definisce la linea lungo cui avviene la sfumatura (dal punto iniziale al punto finale). addColorStop(posizione, colore) aggiunge una "tappa" di colore, dove posizione va da 0 (inizio linea) a 1 (fine linea) — puoi aggiungerne quante vuoi, ad esempio anche una a 0.5 per un colore intermedio.

Gradienti radiali

Sfumano il colore partendo da un cerchio interno verso un cerchio esterno, creando un effetto "a bersaglio" o "a sfera":

const gradiente = ctx.createRadialGradient(x0, y0, r0, x1, y1, r1);
gradiente.addColorStop(0, "colore al centro");
gradiente.addColorStop(1, "colore al bordo");

I sei parametri descrivono due cerchi: centro e raggio del cerchio interno (x0,y0,r0) e centro e raggio del cerchio esterno (x1,y1,r1). Usando lo stesso centro per entrambi si ottiene un effetto radiale simmetrico, molto usato per simulare sfere o luci.

💻 Codice di esempio

// nome, hex, rgb, rgba affiancati
ctx.fillStyle = "tomato";       ctx.fillRect(20, 20, 80, 60);
ctx.fillStyle = "#4f8ef7";      ctx.fillRect(110, 20, 80, 60);
ctx.fillStyle = "rgb(46,204,113)"; ctx.fillRect(200, 20, 80, 60);
ctx.fillStyle = "rgba(155,89,182,0.5)"; ctx.fillRect(290, 20, 80, 60);

// globalAlpha
ctx.globalAlpha = 0.4;
ctx.fillStyle = "black";
ctx.fillRect(20, 20, 350, 60);
ctx.globalAlpha = 1; // riporto opaco

// gradiente lineare
const grad = ctx.createLinearGradient(20, 110, 380, 110);
grad.addColorStop(0, "#ff512f");
grad.addColorStop(1, "#f09819");
ctx.fillStyle = grad;
ctx.fillRect(20, 110, 360, 50);

// gradiente radiale
const gradR = ctx.createRadialGradient(430, 190, 5, 430, 190, 60);
gradR.addColorStop(0, "#ffffff");
gradR.addColorStop(1, "#4f8ef7");
ctx.fillStyle = gradR;
ctx.beginPath();
ctx.arc(430, 190, 60, 0, 2 * Math.PI);
ctx.fill();

8 Pulizia e Reset

Il canvas non "ricorda" le forme che disegni: non sono oggetti come nel DOM, sono solo pixel colorati. Questo significa che per cancellare tutto e ricominciare basta un solo comando, applicato all'intera area:

ctx.clearRect(0, 0, canvas.width, canvas.height);

Usa lo stesso metodo clearRect visto nella sezione 2, ma applicato a tutta la superficie del canvas (da 0,0 fino a larghezza e altezza massime) invece che a una piccola area.

Il pattern render()

Nelle applicazioni interattive (dove il disegno cambia in risposta a click, input, dati aggiornati...) si usa quasi sempre lo stesso schema, chiamato pattern render(): si scrive una funzione (spesso chiamata proprio render) che, ogni volta che viene chiamata:

  1. pulisce tutto il canvas con clearRect;
  2. ridisegna da zero tutto quello che deve essere visibile, basandosi sui dati/stato attuali.

Questo evita di dover "cancellare solo il pezzo che è cambiato" (complicato e soggetto a errori) e garantisce che il disegno sia sempre coerente con lo stato attuale del programma: qualunque cosa cambi, basta richiamare render() e il canvas si aggiorna correttamente. È lo stesso principio usato per aggiornare le pagine HTML con JavaScript (svuotare e riscrivere l'innerHTML), applicato al disegno.

💻 Codice di esempio

function render() {
  // 1. pulisco tutto
  ctx.clearRect(0, 0, canvas.width, canvas.height);

  // 2. ridisegno da zero in base allo stato attuale
  ctx.fillStyle = colori[indiceColore];
  ctx.beginPath();
  ctx.arc(250, 130, 70, 0, 2 * Math.PI);
  ctx.fill();
}

// il pulsante "Pulisci" chiama semplicemente clearRect
document.getElementById("btnPulisci").onclick = () => {
  ctx.clearRect(0, 0, canvas.width, canvas.height);
};

Nell'esempio dal vivo, "Esegui" disegna un cerchio colorato casuale ogni volta (dimostrando render()), mentre il secondo pulsante lo cancella con clearRect.

9 Esempio Completo: Istogramma

Chiudiamo il glossario mettendo insieme tutto quello visto finora in un caso pratico completo: un istogramma (grafico a barre) che mostra quanti studenti hanno preso ogni voto, un esercizio molto comune. Vediamo passo per passo come si costruisce.

1. I dati di partenza

Partiamo da un array che conta quante volte compare ogni voto, ad esempio indice 0 = voto 1 (nessuno), fino a indice 10 = voto 10. Nell'esempio useremo un array di 11 posizioni con il conteggio degli studenti per ogni voto da 0 a 10.

2. Gli assi cartesiani

Prima delle barre disegniamo due linee di riferimento: l'asse X orizzontale (in basso) e l'asse Y verticale (a sinistra), spesso tratteggiate per non "sporcare" troppo il disegno. Le linee tratteggiate si ottengono con ctx.setLineDash([5, 5]) prima di stroke() (poi si torna alla linea continua con ctx.setLineDash([])).

3. Le barre proporzionali

Ogni barra è un semplice fillRect. La parte più delicata è calcolare altezza e posizione in proporzione ai dati:

  • si calcola quanto spazio orizzontale spetta a ogni barra dividendo la larghezza utile del grafico per il numero di voti;
  • si calcola un "fattore di scala" verticale confrontando l'altezza disponibile con il valore massimo tra i dati, così il valore più alto occupa quasi tutta l'altezza del grafico e gli altri sono proporzionati di conseguenza;
  • la barra si disegna partendo dal basso: la sua coordinata y è (altezza totale del grafico) - (altezza della barra), perché ricordiamo che y cresce verso il basso (sezione 1) e quindi "in alto" significa y più piccola.

4. Le etichette sull'asse X, con un for

Sotto ogni barra scriviamo il voto corrispondente con fillText, dentro un for (o forEach) che scorre l'array dei dati: ad ogni iterazione cambia solo la coordinata x (in base all'indice) mentre il testo cambia in base al valore.

5. I numeri sull'asse Y, con un for

Allo stesso modo, a fianco dell'asse Y si scrivono con un altro for alcuni valori numerici di riferimento (es. 0, 2, 4, 6...) per capire a colpo d'occhio quanto vale l'altezza delle barre, usando lo stesso fattore di scala calcolato al punto 3 per posizionarli correttamente.

6. La scritta verticale "Quantità"

Per etichettare l'asse Y nel suo complesso si scrive "Quantità" ruotato di 90°, esattamente con lo schema della sezione 6: save() → translate() nel punto a sinistra dell'asse Y → rotate(-Math.PI/2) → fillText() → restore().

Il risultato finale è un grafico completo, leggibile e proporzionato, costruito solo con i metodi visti in questo glossario: fillRect, path per gli assi tratteggiati, fillText nei due for, e la rotazione per l'etichetta verticale.

💻 Codice di esempio (semplificato)

const voti = [0, 0, 0, 1, 2, 5, 8, 6, 4, 2, 1]; // indice = voto, valore = n. studenti
const max = Math.max(...voti);
const margine = 50;
const larghezzaUtile = canvas.width - margine - 20;
const altezzaUtile = canvas.height - margine - 20;
const larghezzaBarra = larghezzaUtile / voti.length;
const scalaY = altezzaUtile / max;

// assi
ctx.beginPath();
ctx.moveTo(margine, 20);
ctx.lineTo(margine, altezzaUtile + 20);
ctx.lineTo(margine + larghezzaUtile, altezzaUtile + 20);
ctx.stroke();

voti.forEach((valore, voto) => {
  const altezzaBarra = valore * scalaY;
  const x = margine + voto * larghezzaBarra;
  const y = (altezzaUtile + 20) - altezzaBarra;

  ctx.fillStyle = "#4f8ef7";
  ctx.fillRect(x + 4, y, larghezzaBarra - 8, altezzaBarra);

  // etichetta voto sotto la barra (asse X)
  ctx.fillStyle = "#333";
  ctx.textAlign = "center";
  ctx.fillText(voto, x + larghezzaBarra / 2, altezzaUtile + 35);
});

// numeri sull'asse Y
for (let v = 0; v <= max; v += 2) {
  const y = (altezzaUtile + 20) - v * scalaY;
  ctx.fillText(v, margine - 15, y);
}

// scritta verticale "Quantità"
ctx.save();
ctx.translate(15, altezzaUtile / 2 + 20);
ctx.rotate(-Math.PI / 2);
ctx.textAlign = "center";
ctx.fillText("Quantità", 0, 0);
ctx.restore();
